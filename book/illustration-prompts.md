# Chapter Illustration Prompts

One prompt per chapter, written to be pasted into an image generator on its own. Every prompt carries the same style block so the twenty images look like one set and match the cover. Each one asks for a landscape 3:2 image (about 1800 x 1200 px), which sits across the width of a 6 x 9 page at the start of a chapter.

**Recurring character:** the stressed-out cloud from the cover appears in every picture, usually small and in a corner, reacting to the scene. Readers will start looking for it.

**Style block used in every prompt:** Retro-pop editorial illustration: thick clean dark-indigo outlines, flat saturated colour with simple cel shading, subtle halftone dot texture, playful 1950s sci-fi poster mood. Palette of deep indigo, magenta, hot orange, lemon yellow, and cyan with white highlights. Strong shapes and high contrast so it still reads when printed in greyscale. No text, letters, numbers, logos, or watermarks. No real people's faces: any human figure is a small, faceless or stylised silhouette.
